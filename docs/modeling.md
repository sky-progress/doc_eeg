# 建模重建

2026-10-14，用户要求删除本项目旧建模代码，从头设计实现。
当前仅完成清理，没有新训练入口，也没有启动新的模型实验。
历史实验说明随旧源码归档，数据区域的历史结果继续保留。

## 已讨论的职责划分

- `preprocessing/`继续负责数据生成，不承担训练时的数据加载。
- `src/datasets/`负责任务纳排、诊断映射、患者划分和窗口读取。
- `src/models/`负责每个模型自己的输入适配和网络创建。
- `src/training/`负责共用深度学习训练、验证、早停及权重保存。
- `src/evaluation/`负责预测汇总、指标与混淆矩阵。
- `third_party/`保存新接入的官方源码、许可证和版本信息。
- 拟采用统一运行入口，通过配置选择任务和模型；尚未创建入口。
- 传统机器学习共用任务、划分和评价，但拟合流程与深度学习分别实现。

## 数据与标签约定

主表保留原始诊断，任务定义负责类别映射，不因二分类合并改写原诊断。
支持未来二分类、三分类、五分类；具体类别、边界诊断和纳排仍需确认。
不能从总分、数据目录或患者ID前缀推断任务标签。

同一患者的所有测试及窗口在训练、验证和测试之间不得跨集合，
内层和外层划分都使用患者ID。不同测试的诊断可能不同，
不能未经任务约定将不同阶段的预测平均为一个患者标签。
HC_011_WAN是已确认的康复后记录，作为健康对照的纳排需单独确定。

归一化、缺失值插补、特征选择及其他拟合操作只使用当轮训练数据。
验证数据用于选择模型和参数，测试数据不参与早停、阈值或调参。
各模型在同一任务上使用相同的队列与划分，运行时保存标签及参数快照。

新代码遵循AGENTS.md中的工程规范。具体脚本、交叉验证方案、
评价层级及模型参数将在实现前讨论，不自动沿用旧实验设置。
